platmon APT repository

Signed APT repository for the platmon Debian package. It holds the same .deb files as the GitHub releases; platmon-hub is installed from PyPI.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://platmon.github.io/apt/platmon-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/platmon.gpg > /dev/null
gpg --show-keys /etc/apt/keyrings/platmon.gpg
sudo tee /etc/apt/sources.list.d/platmon.sources > /dev/null <<'EOF'
Types: deb
URIs: https://platmon.github.io/apt
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/platmon.gpg
EOF
sudo apt update
sudo apt install platmon

Signing key

Check that gpg --show-keys prints this fingerprint before running apt update:

6D42 C14A BFB9 412F 34BA 4BEF F38B 9BB5 26A3 B0C6

Ed25519, created 2026-10-18, expires 2028-10-17. Also available as ASCII armor.

Upgrades, rollback with apt install platmon=<version> and configuration handling are described in the packaging guide.
