INSTALL

Install platmon on your device.

The service starts with the install. The web page, the platmon command and the tray come with it.

Check the network firstOn Linux the service listens on all IPv4 interfaces (0.0.0.0:9797) without authentication. Anyone who can reach the port can read the host name, kernel, interfaces and other readings. Use a trusted network, or set bind in /etc/platmon/platmon.ini. The Windows packages listen on 127.0.0.1 only.Choose what is served ↗

Ubuntu and Debian

Ubuntu and Debian-derived systems with systemd, including Jetson and Raspberry Pi OS, on amd64, arm64 and armhf.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://platmon.github.io/apt/platmon-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/platmon.gpg > /dev/null
gpg --show-keys /etc/apt/keyrings/platmon.gpg
sudo tee /etc/apt/sources.list.d/platmon.sources > /dev/null <<EOF
Types: deb
URIs: https://platmon.github.io/apt
Suites: stable
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/platmon.gpg
EOF
sudo apt update
sudo apt install platmon

Before apt update, check that gpg --show-keys prints this fingerprint:

6D42 C14A BFB9 412F 34BA 4BEF F38B 9BB5 26A3 B0C6

Update with sudo apt update && sudo apt upgrade. If platmon-cli from 1.7.0–1.10.0 is installed, run sudo apt install platmon-frontend once: until then apt upgrade keeps platmon back.

Earlier versions stay in the repository, so sudo apt install platmon=<version> rolls back. Rolling back to 1.10.0 or earlier removes platmon-frontend.

Other ways to install

Every way runs the same server. Release files come with SHA256SUMS.

You haveUse

Fedora or Enterprise Linux 9+The unsigned .rpm packages (x86_64, aarch64) from GitHub Releases. RPM packages ↗

After installing

  1. 1

    Check the service

    It should be active, and one snapshot should print.

    systemctl status platmon --no-pager
    platmon --once
  2. 2

    Open a view

    Run platmon, or open the device address in a browser.

    http://<device-address>:9797
  3. 3

    Add more devices

    Run platmon-hub on another computer to see every device in one place.

    platmon-hub →
