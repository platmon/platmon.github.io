PLATMON-HUB

Many devices.
One platmon-hub.

Run Hub on Windows or Linux. It reads each device's HTTP API and shows their readings in one dashboard.

Python 3.9+ · No third-party dependencies · Apache-2.0

LIVE

Every device in one dashboard

Readings and status from each registered device, side by side.

RECORD

History, alerts and exports

Optional SQLite history, internal alerts and data exports.

INDEPENDENT

Devices keep collecting

Devices run on their own when Hub stops. Hub never installs or controls them, and its HTTP is read-only by default.

Which Hub release reads which platmon release is in the compatibility table ↗.

Install Hub

Requires Python 3.9+ and pipx.

pipx install platmon-hub
platmon-hub --version

Start with an empty device list in the current directory, keep the terminal running, and open http://127.0.0.1:9787/ on the same computer. Zero devices is expected.

Linux

echo '{"nodes": []}' > nodes.json
platmon-hub --nodes ./nodes.json

Windows PowerShell

Set-Content -Path nodes.json -Value '{"nodes": []}' -Encoding ascii
platmon-hub --nodes .\nodes.json

Update with pipx upgrade platmon-hub. This is a personal install: for a service, a Windows startup task or an upgrade that keeps history, follow the operations guide.

Hub listens on loopback by default. Keep the first run there.
